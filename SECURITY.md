# Security policy

Report suspected vulnerabilities through GitHub **Security → Advisories → Report a vulnerability** (private vulnerability reporting). If reporting is not enabled yet, wait for the maintainer to enable it; do not post credentials, account details, tokens, raw notifications or exploit details in a public issue.

Supported version: the latest published source release. This personal project has no guaranteed response time or security warranty. Keep banking credentials, FCM state, SQLite data, webhook secrets and backups private. Rotate compromised credentials and stop the affected deployment until investigated.
